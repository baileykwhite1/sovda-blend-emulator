# SOVDA Blend emulator

Software emulator of the SOVDA Blend and its Smart Line Plus touch panel, for technician training in the SOVDA Tech Academy.
Single file: `index.html`. Source of truth lives in the Sorted workspace at `manual-control/emulators/sovda-blend-emulator.html`; copy it here as `index.html` to release.

Hopper sizes, transfer rates and pressure behaviour are illustrative, not machine specifications.
